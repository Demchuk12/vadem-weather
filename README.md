# Vadem Weather

Погодний застосунок на Vue 3 (Composition API) + TypeScript + Pinia з даними [OpenWeatherMap](https://openweathermap.org/).

**Demo:** https://vadem-weather.vercel.app

## Стек

- Vue 3, `<script setup>`, TypeScript (strict)
- Pinia — стан блоків, вибраного, налаштувань і кеш погоди
- Vue Router — вкладки «Головна» / «Вибране»
- Chart.js без обгорток
- Чистий CSS з дизайн-токенами, без CSS-фреймворків і UI-бібліотек
- Vitest, ESLint, Prettier

## Запуск

```bash
npm install
cp .env.example .env   # вкажіть VITE_OWM_API_KEY
npm run dev
```

| Команда | Опис |
| --- | --- |
| `npm run dev` | dev-сервер |
| `npm run build` | type-check і production-збірка |
| `npm run test` | unit-тести (Vitest) |
| `npm run test:coverage` | unit-тести з покриттям |
| `npm run test:e2e` | e2e-тести (Playwright) |
| `npm run lint` | ESLint |

## Тести

- **Unit** (`tests/unit`, Vitest + happy-dom): утиліти, HTTP-клієнт, сервіси, Pinia-стори, композабли, конфіг графіка.
- **E2E** (`tests/e2e`, Playwright): сценарії користувача на десктопі та мобільному (360px). Запити до OpenWeatherMap і IP-сервісів підмінюються фікстурами, тому ключ API не потрібен.

Перед першим запуском e2e: `npx playwright install chromium`.

## Функціонал

- Пошук міста з автокомплітом (Geocoding API, debounce, керування з клавіатури)
- Картка поточної погоди та графік температури на найближчі 24 години
- Перемикач «День / 5 днів»: прогноз по днях із середньою температурою, розрахованою з погодинних даних
- Перемикач «День / Ніч»: денна чи нічна статистика, підсвічування відповідних годин на графіку, окремі іконки та фон картки
- До 5 блоків погоди, видалення з підтвердженням
- Вибране (до 5 міст, зберігається в localStorage); при перевищенні ліміту — модальне вікно з вибором міста для заміни
- Визначення міста за IP (geojs.io, резервно ipapi.co, далі Київ)
- Скелетони та лоадери під час запитів
- Інтерфейс і відповіді API українською та англійською
- Адаптивна верстка 360–1200px

## Додатково

- Світла й темна теми (за замовчуванням — системна), без мерехтіння при завантаженні
- Власні анімовані SVG-іконки погоди
- Кешування відповідей на 10 хвилин і об'єднання однакових запитів між вкладками
- Блоки на головній зберігаються між сесіями
- Кнопка оновлення даних, час останнього оновлення
- Час і дати відображаються в часовому поясі обраного міста
- Деталі: вологість, вітер із напрямком, тиск, видимість, схід і захід сонця
- Імовірність опадів на графіку та у прогнозі по днях
- Доступність: ARIA для combobox, radiogroup і модалок, фокус-трап, підтримка `prefers-reduced-motion`

## Структура

```
src/
  api/          HTTP-клієнт і запити до OpenWeatherMap та IP-сервісів
  services/     збирання даних для UI
  stores/       Pinia-стори
  composables/  перевикористовувана логіка
  charts/       конфігурація Chart.js і плагін підписів
  components/   ui / layout / weather
  views/        сторінки
  i18n/         переклади
  utils/        чисті функції (агрегація прогнозу, форматування)
  types/        DTO API та доменні типи
tests/
  unit/         unit-тести
  e2e/          e2e-тести
  fixtures/     спільні фікстури відповідей API
```
